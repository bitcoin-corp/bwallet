# bWalletX walkthrough 01: "One wallet for everything"

Draft for owner approval · 5 Oct 2026 · target ~75 s · ~185 words of voiceover
Recorded on the web app at phone size (390×844) with a fresh test wallet (no real funds).
Voices: Jessica (female) and Brian (male), both American (ElevenLabs). One cut each. Each scene's length is set by its generated voice line.

## Notes and checks before recording

- Scene 7–8 need the b agent to answer. With a paid b account that costs a few cents per reply; with an own API key it uses that key. Either way the reply is real, not staged. If b's actual answer differs, the voiceover for scene 8 stays generic ("It writes the rules…") so it still matches.
- The test wallet holds no money, so balances show $0.00. For scene 4 that's honest; we don't fake balances.
- Exchange listings shown are real public listings at the time of recording.
- Exports: 16:9 1920×1080 for X, 9:16 1080×1920 for Reels/TikTok (phone fills the frame), 1:1 optional. Burned-in captions from the script.
- Load on the external drive: record to the internal disk (/tmp), one scene at a time, encode once at the end.
